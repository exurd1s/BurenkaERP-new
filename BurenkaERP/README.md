# 🐄 Бурёнка ERP v4.0
**Production-ready ERP-система управления молочным стадом**

## 🚀 Возможности
- **Полный CRUD**: коровы, сотрудники, ветзаписи, репродукция, надои, склад
- **Персистентность**: все данные сохраняются в localStorage
- **Графики Chart.js**: динамика надоя, состояние стада, финансы
- **Экспорт**: Excel (SheetJS), PDF (jsPDF), JSON
- **Импорт CSV**: drag&drop коров из таблицы
- **Command Palette**: глобальный поиск по `Ctrl+K`
- **Notification Drawer**: панель уведомлений справа
- **QR-коды**: генерация для каждой коровы
- **Голосовой ввод**: Web Speech API для дояров
- **PWA**: установка на телефон, офлайн-режим
- **Роли**: 9 ролей с разграничением прав
- **Аудит-лог**: журнал всех действий пользователей
- **Тёмная тема**: плавное переключение
- **Адаптивность**: мобильная, планшетная, десктопная версии
- **Анимации**: confetti, number counter, skeleton loaders
- **Валидация**: маски телефона и бирки, обязательные поля

## 🛠 Технологический стек
- **Vanilla JS (ES6+)**: модульная архитектура
- **Chart.js 4.4**: визуализация данных
- **SheetJS**: экспорт в Excel
- **jsPDF + AutoTable**: экспорт в PDF
- **QRCode.js**: генерация QR-кодов
- **Canvas Confetti**: праздничные анимации
- **Web Speech API**: голосовой ввод
- **Service Worker**: PWA и офлайн

## 📦 Запуск
1. Сохраните все файлы в одну папку
2. Откройте `index.html` в современном браузере
3. Для PWA рекомендуется локальный сервер: `python -m http.server 8000`
4. Демо-доступ: **admin** / **12345rfr**

## 📱 PWA
Сайт можно установить как приложение:
- **iOS**: Safari → «На экран Домой»
- **Android**: Chrome → меню → «Установить приложение»
- **Desktop**: Chrome → адресная строка → иконка установки

## 📊 Структура данных
- `users` — пользователи системы
- `cows` — реестр КРС
- `staff` — сотрудники
- `healthRecords` — медицинские записи
- `milkRecords` — надои
- `stockOps` — складские операции
- `drugs` — справочник препаратов
- `hayStock` — запасы кормов
- `systemLogs` — аудит-лог
- `notifications` — уведомления

## 🎨 Дизайн
- Палитра: Modern Agro (зелёно-земляные тона)
- Шрифты: Inter (UI), JetBrains Mono (цифры)
- Радиусы: 6/10/14/20px
- Тени: 5 уровней с цветным оттенком
- Анимации: 60fps, cubic-bezier

## 🔐 Безопасность (для production)
Для реального развёртывания рекомендуется:
- Бэкенд на Node.js/Express
- PostgreSQL вместо localStorage
- JWT + bcrypt для аутентификации
- HTTPS и защита от XSS/CSRF
- Rate limiting и валидация на сервере
